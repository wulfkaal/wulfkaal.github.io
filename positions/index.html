Positions
  1. Agentic AI governance should be organized around action level accountability. A governance roadmap is incomplete unless it can reconstruct the agent action, delegated mandate, evidence used, review path, and downstream effect. 2026-07-31
  2. MCP governance should be treated as a continuous institutional process, not as a sequence of static releases. Discovery, authorization, tool permissions, and observed failure data require an auditable review mechanism that can adapt rules without erasing accountability. 2026-07-31
  3. DAO governance must be assessed at the level of power allocation and execution exposure, not only procedural form. A voting process does not establish decentralization when purchasable influence, delegation concentration, or automatic execution leave governance open to capture. 2026-07-31
  4. DAO governance should be evaluated by explicit resistance to capture, participation collapse, and collective-action failure. Token voting is an input, not evidence that those failure modes have been solved. 2026-07-30
  5. Machine agency governance must preserve action-level attribution across delegation chains. Architecture diagrams and policy statements are insufficient if a reviewer cannot reconstruct which agent acted, under whose authority, using which evidence, and with which downstream effect. 2026-07-30
  6. Decentralized AI architecture should evaluate incentive compatibility separately from technical distribution. A system is not institutionally decentralized merely because agents, wallets, and execution are distributed. 2026-07-30
  7. Agentic payment design must couple programmable settlement with bounded mandates, transaction-level provenance, revocation, and accountable loss allocation. Efficient settlement without institutional controls scales the consequences of error. 2026-07-30
  8. Agentic commerce protocols need a portable, verifiable performance layer that records completed transactions, disputes, reversals, and validated outcomes without collapsing reputation into a single platform score. 2026-07-30
  9. An agent identity standard is incomplete unless it binds identity to a verifiable mandate, attributes action to a principal, and makes costly evasion of negative history part of the design. 2026-07-30
  10. MCP governance should be treated as a continuous institutional process, not as a sequence of static specification releases. Server behavior, tool permissions, and observed failure data should feed a review mechanism that can update rules while preserving an auditable record. 2026-07-30
