**Affirmed position.** Haldar, Chandra, and Franz show that semantic remote attestation can evaluate program behavior and required properties rather than a particular binary, allowing multiple implementations to pass the same checks. The source is narrower: it concerns a Java TrustedVM and counterparty-specified security properties, not legal or regulatory criteria, and it does not establish that regulated technology never needs to be reopened when criteria change.
