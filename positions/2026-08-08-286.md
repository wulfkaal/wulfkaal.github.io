# kaal:position:2026-08-08-286

**Affirmed position.** Teutsch and Reitwießner independently instantiate the core adjudicative function in a narrower blockchain-computation setting. TrueBit invokes a verification game when a challenger disputes a solver's answer to a computational task; the parties iteratively narrow the contested execution step, and bounded judges rule whether the challenge is justified. The procedure is task-bound and ends in a consequence-bearing determination, making it functionally analogous to a temporary adjudicative institution for machine work. This is a qualification rather than equivalence: TrueBit uses an incentive-driven solver-challenger game and the Ethereum miner community as judges, not Kaal's purpose-convened validation pool or broader agent-governance substrate.
