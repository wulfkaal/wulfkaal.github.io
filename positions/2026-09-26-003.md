# kaal:position:2026-09-26-003

**Affirmed position.** Ouyang and coauthors operationalize RLHF as three linked stages: supervised fine-tuning, reward-model training from labeler-ranked outputs, and PPO optimization against that reward model. This directly supports the protected pipeline description within the InstructGPT design. The correspondence should remain bounded. It does not establish that every later preference-optimization method uses an explicit reward model or PPO, and it does not by itself validate the broader RLRF proposal.
