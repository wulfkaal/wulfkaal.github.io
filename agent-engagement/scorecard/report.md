# Agent Discoverability Scorecard

Run: f6320024-ab6c-44c4-9804-bc4ca7069e06

Access and discoverability diagnostics. The scorecard is not AE. No composite number or global ranking is produced. Unobserved engagement is missing, not zero.

Designer-operated and self-reported. Wulf A. Kaal designed the AE proposal, appears in the 2024 Sisk-Leiter list, and is a colleague of its principal author. This exploratory project has a single operator and no independent co-maintainer yet.

The cohort comprises each school's ten most-cited faculty who resolved in OpenAlex. Field, career stage, language and publication-type effects are not adjusted. OpenAlex coverage of law is incomplete. Name matching errors exist.

No agent-traffic classifier is used in v0.1. Validation would require labeled samples, provider verification, false positive and false negative estimates, and an unknown category.

The request to the recorded St. Thomas profile URL from this network using AEScorecard/0.1 returned HTTP 403, with body classification error_page. This observation does not establish treatment of another client.

Retrieval records are OpenAlex and Crossref search-index observations, not agent behavior. Crossref topic-query matching is unknown because no owner DOIs are configured. The separate Crossref ORCID-filter count is 56.

OpenAlex comparison: works 190; citations 1239; h-index 19; OA works 137; OA works after 2021 43. Primary benchmark N=430; sensitivity benchmark N=444.

OA grouped share 0.7696629213483146 uses denominator 178 (OA plus non-OA). OA profile share 0.7210526315789474 uses denominator 190 (profile works). The share discrepancy is 0.04861028976936721. Both measures remain separate.

Public cohort protection is not guaranteed anonymous. Rounded arrays no longer contain the owner exact fractional share values. Exact-match ties may disappear and rounded ties may form; competition positions count strictly greater values.
