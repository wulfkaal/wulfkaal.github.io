# kaal:claim:1998455-027

**Claim.** Where jurisdictions are not compelled to agree on the same rule, some jurisdiction will try a different rule, and will do so more quickly, when changed economic circumstances make a different rule optimal.

**Type.** mechanism  **Support.** argued

**Holds when.**

- where jurisdictions are not compelled to converge on a single rule
- where underlying economic circumstances change so that a different rule would be optimal

**Source quote.**

> diction will try a different rule, and will do so more quickly, than if all jurisdictions felt compelled to agree upon the same rule.
