kaal:claim:7598518-036

Claim. The design binds in one file, frozen by hash only after twenty-two rounds of blind audit by two model engines, and every harness and analysis step refuses to run against a design whose hash differs.

Type. mechanism · Support. stated

Holds when

  • Every random draw derives from a named hash template, so no draw depends on anything outside its listed fields.
  • The auditing engines are model engines and are not independent peer review.

Source quote

The design binds in one file, frozen by hash only after twenty-two rounds of blind audit by two model engines, the last of which both passed with no findings. Every harness and analysis step refuses to run against a design whose hash differs.

From. Wulf A. Kaal, Can Reputation Prevent Model Collapse? A Preregistered Test of Reputation-Weighted Data Filtering (2026). Full text.
