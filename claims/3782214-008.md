# kaal:claim:3782214-008

**Claim.** Fundamental rule changes in a large decentralized organization are typically demanded when a large minority is treated unfairly, which means the advantaged majority has no incentive to make the change; the resulting deadlock leaves revolution or a network split as the only route to foundational change.

**Type.** failure  **Support.** argued

**Holds when.**

- large decentralized organizations
- rules that advantage the majority

**Source quote.**

> When a large decentralized organization needs a fundamental rule change, it of- ten happens because a large minority subgroup is being treated unfairly. That typically means the majority is advantaged by the rules and are therefore not incentivized to change the rules.

**From.** Craig Calcaterra, Wulf A. Kaal, *Decentralized Governance* (2021), Chapter 6. Governance, page 5
