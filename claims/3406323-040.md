# kaal:claim:3406323-040

**Claim.** For any static set of rules in an infinitely repeated game using reputation stakes there is a way to subvert the rules for individual profit at the expense of the group, a result the author attributes to the Folk Theorems of game theory.

**Type.** failure  **Support.** argued

**Holds when.**

- infinitely repeated games using reputation or stakes
- static rule sets

**Source quote.**

> For any static set of rules in an infinitely repeated game using reputation (stakes), there is a way to subvert the rules for an individual's profit at the expense of the group.

**From.** Wulf A. Kaal, *Decentralization - A Primer on the New Economy* (2019), VII. Ethical Governance, page 19
