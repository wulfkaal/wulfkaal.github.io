# kaal:claim:3396542-005

**Claim.** Tokens in the proposed DAO function as reputation because an agent's proportional token holdings will grow over time only if that agent follows sound and successful underwriting practices.

**Type.** mechanism  **Support.** argued

**Holds when.**
