# kaal:claim:3782201-020

**Claim.** Bitcoin demonstrates the power of decentralized cooperation and transparency: after a decade without centralized oversight, no network transaction has sent the wrong quantity or gone to the wrong account and no bug has produced an accounting error in a system worth hundreds of billions of dollars.

**Type.** empirical  **Support.** evidenced

**Holds when.**

- applies to the network protocol itself, not to the centralized service organizations built on it, from which billions have been stolen

**Source quote.**

> No digital token has ever disappeared or was mistakenly duplicated. Not a single bug has been found to create any type of accounting error in a system worth hundreds of billions of dollars.
