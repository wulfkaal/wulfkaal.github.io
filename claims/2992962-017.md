# kaal:claim:2992962-017

**Claim.** Because smart contracts are coded for computer programming rather than for a human observer, courts may not be able to hypothesize a reasonable human's interpretation of a given smart contract.

**Type.** failure  **Support.** argued

**Holds when.**

- contract interpretation disputes over coded smart contracts

**Source quote.**

> Because of the emphasis on code for computer programming (and artificial intelligence), courts may not be able to hypothesize a reasonable human's interpretation of a given smart contract.
