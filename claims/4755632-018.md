# kaal:claim:4755632-018

**Claim.** Hierarchical review produces an anchoring failure: the first reviewer in the hierarchy gets the highest priority and follow-on reviewers merely add minor upgrades, so adding reviewers does not add the independent scrutiny that would raise code quality.

**Type.** failure  **Support.** argued

**Holds when.**

- applies to legacy hierarchical code review processes

**Source quote.**

> in the legacy review process, the first reviewer within the hierarchical structure of the code review process often gets the highest priority and is often merely followed with minor upgrades by follow-on reviewers.

**From.** Wulf A. Kaal, *AI Learning - Decentralized Governance to Optimize Human Output Datasets for AI Learning* (2024), Market for Code Reviews, page 34
