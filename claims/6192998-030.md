# kaal:claim:6192998-030

**Claim.** Honest ranking strictly dominates strategic ranking for validators whenever the reputation gain from consensus alignment matters, so truth telling is a Bayesian Nash equilibrium.

**Type.** mechanism  **Support.** argued

**Holds when.**

- validators believe the stake weighted plurality will vote honestly
- reputation value exceeds the immediate payment for validating
