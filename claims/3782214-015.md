# kaal:claim:3782214-015

**Claim.** Rigid code is law smart contracts over fungible currency are built to guarantee irreversible, unreviewable, self executing outcomes, which is a poor match for business because business ventures very rarely proceed exactly as imagined at the outset.

**Type.** failure  **Support.** argued

**Holds when.**

- contracts involving fungible currency exchange
- commercial arrangements with uncertain execution
