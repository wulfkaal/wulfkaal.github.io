# kaal:claim:4015908-038

**Claim.** Non-linear reward structures using weighting, tiers, or logarithmic curves counteract centralization of token supply by decentralizing disproportionate returns so that rewards do not scale linearly with the amount of liquidity a user holds.

**Type.** design  **Support.** argued

**Holds when.**

- fair launch protocol designing its reward structure

**Source quote.**

> Fair launch protocols can create some form of weighting, tier, and/or logarithmic curves for rewards. This decentralizes disproportionate returns, so they do not scale linearly with the amount user liquidity a user has.
