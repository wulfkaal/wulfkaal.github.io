# kaal:claim:6607458-039

**Claim.** Existing national accounts are built to measure terminal human consumption and therefore fail to capture intermediate value created in agent-to-agent transaction chains, so the measurement apparatus requires reconstruction.

**Type.** failure  **Support.** argued

**Holds when.**

- applies where value is created in agent-to-agent chains with no intervening human consumption event

**Source quote.**

> Existing national accounts are designed to measure terminal human consumption and do not capture intermediate value created in agent-to-agent transaction chains where no human consumption event occurs at any step prior to the terminal output. The measurement apparatus requires reconstruction.
