# kaal:claim:4941807-012

**Claim.** Federated learning does not eliminate privacy risk, because although the data stays decentralized the protocol still exchanges model parameters, and those parameters can expose sensitive information if intercepted or improperly handled.

**Type.** failure  **Support.** argued

**Holds when.**

- in federated learning deployments that exchange model parameters
- where parameters can be intercepted or mishandled

**Source quote.**
