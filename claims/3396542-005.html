kaal:claim:3396542-005

Tokens in the proposed DAO function as reputation because an agent's proportional token holdings will grow over time only if that agent follows sound and successful underwriting practices.

Source quote, verbatim
We will refer to these tokens on occasion as reputation tokens as an agent's proportional holdings of these tokens is likely to increase over time only if the agent were to follow sound and successful underwriting practices.
