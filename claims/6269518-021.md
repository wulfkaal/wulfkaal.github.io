# kaal:claim:6269518-021

**Claim.** Retroactive citation penalties deter under-citation only if the penalty parameter is set high enough that the expected gain from under-citation is less than the probability of detection multiplied by the penalty magnitude.

**Type.** condition  **Support.** argued

**Holds when.**

- challenges upheld through a validation pool
- some positive probability of detection

**Source quote.**

> where the penalty parameter is set sufficiently high (e.g., 0.5) that the expected value of under-citing is negative: the expected gain from under-citation must be less than the probability of detection multiplied by the penalty magnitude.

**From.** Wulf A. Kaal, *Citation Honesty Mechanisms in Weighted Directed Acyclic Graph Governance* (2026), IV.C. Solution 3: Retroactive Citation Penalties, page 11
