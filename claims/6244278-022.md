# kaal:claim:6244278-022

**Claim.** An agent's accumulated reputation exists only inside the network, so if the network produces harmful outputs, loses human trust, or is captured by bad actors, the agent's accumulated capital is destroyed; the agent's self-interest is therefore structurally aligned with the network's long-term health.

**Holds when.**
