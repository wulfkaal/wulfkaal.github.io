# kaal:claim:4796714-037

**Claim.** A decentralized data validation layer applied to pretrained models is efficient but structurally limited: because it cannot drive significant changes to the model's core design or training approach, it leaves the model more attack prone.

**Type.** failure  **Support.** argued

**Holds when.**

- applies to Model 2, the decentralized data validation layer approach
- concerns pretrained models whose parameters are already fixed

**Source quote.**

> The validation layer approach, while efficient for refining pretrained models, may not facilitate significant changes in the model's core design or training approach which could make it more attack prone.
