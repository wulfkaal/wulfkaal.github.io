# kaal:claim:3411110-002

**Claim.** When multiple firms trade the same securities in legacy systems, each maintains its own ledger, and that duplication is itself the source of increased operational risk and cost.

**Type.** mechanism  **Support.** asserted

**Holds when.**

- multiple firms trading the same security
- legacy multi ledger systems

**Source quote.**

> Legacy systems in which multiple firms are trading the same securities utilize multiple ledgers which increases operational risks and increases costs.
