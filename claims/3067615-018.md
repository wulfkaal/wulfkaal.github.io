# kaal:claim:3067615-018

**Claim.** The 2012 to 2017 ICO model allowed cryptocurrencies to be raised through a token sale without any conditions, landmark requirements, or security measures to protect investors, so that in essence promoters could use ICO proceeds as they pleased.

**Type.** failure  **Support.** argued

**Holds when.**

- ICO models prevailing between 2012 and 2017

**Source quote.**

> First and foremost, the 2012-2017 ICO models allowed cryptocurrencies to be raised via a token sale without any conditions, landmark requirements, or security measures to protect investors.
