# kaal:claim:7456999-063

**Claim.** The sweep's reported RLRF accuracy above 0.97 is an output of parameters set by the sweep, not a measurement of a system.

**Type.** failure  **Support.** asserted

**Holds when.**

- Finding 2 of the parameter sweep

**Source quote.**

> Mean accuracy for RLRF exceeds 0.97 across the four simulated experiments, against 0.68 for the modeled RLHF baseline. This is the sweep’s headline number and it is an output of parameters the sweep sets: the simulated parties are distributions whose per- party accuracy is an input to the run. It is not a measurement of any system.
