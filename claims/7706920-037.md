# kaal:claim:7706920-037

**Claim.** After an adjudicated harm the agent stays if and only if the smaller of the harm and its garnishable earnings is at most its exit-side capacity, and an agent that exits leaves the injured party with nothing.

**Type.** mechanism  **Support.** argued

**Holds when.**

- Conditional on the single-agent, deterministic, stationary model of Part V.A, with an agent whose only assets are its earnings and its record.
- Ties are resolved in favor of staying.

**Source quote.**

> After an adjudicated harm of size D, the agent stays if and only if min{D,E} ≤ X, equivalently D ≤ X or X ≥ E. If it stays, the injured party recovers ρ(D) = min{D,E}. If it exits, the injured party recovers ρ(D) = 0.
