# kaal:claim:3396542-018

**Claim.** The DAO design requires that the value of the tokens staked on a set of policies be large enough to cover the maximum possible liability on those policies, which in turn imposes a minimum condition on the premium charged.

**Type.** condition  **Support.** argued

**Holds when.**

- steady state model with constant M and p

**Source quote.**

> The design of the DAO requires that v1 should be large enough to cover the maximum possible liability on the M policies against which these tokens are to be encumbered. We will later derive a condition on the premium
