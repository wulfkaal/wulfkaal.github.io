kaal:claim:3808859-009

Peer-to-peer architecture inverts the role of the audience: higher demand for a file produces more seeding nodes, which lowers the per-file delivery cost, whereas in client-server architecture demand consumes bandwidth proportionally.

Source quote, verbatim
By contrast, in the peer-to-peer network, higher demand for a file triggers higher levels of seeding nodes for the high demand file. The higher seeding level for the file lowers the delivery cost for each distributed file.
