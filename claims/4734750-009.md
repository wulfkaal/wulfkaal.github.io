# kaal:claim:4734750-009

**Claim.** Multiple reviewers asking clarifying questions tends to make code simpler and clearer and therefore higher quality, but hierarchical review processes structurally block this mechanism.

**Type.** mechanism  **Support.** argued

**Holds when.**

- code review settings that permit many independent reviewers

**Source quote.**

> the more people review the code with comments that ask for clarification, the more likely it becomes that the code becomes simpler and clearer, which in turn typically increases code quality. However, that is not possible in hierarchical review processes.
