# kaal:claim:3125827-035

**Claim.** Because each sem token carries a different value depending on the post that minted it and on its position in the reference graph, the total value is difficult to determine, which makes it almost impossible to execute a 51% attack by purchasing tokens on an exchange.

**Type.** mechanism  **Support.** argued

**Holds when.**

- token value derived from position in the forum WDAG
- most tokens constantly in use and continually created

**Source quote.**

> their value is difficult to determine since each token has a different value depending on the post in which it was minted. So it is almost impossible to execute a 51% attack by purchasing tokens on an exchange.
