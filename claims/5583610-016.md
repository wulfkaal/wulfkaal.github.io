# kaal:claim:5583610-016

**Claim.** Under Blasius, LER should function as a last-resort tool justified by evidence of severe harm to the corporation, such as an activist's documented history of value destruction, so that courts can test whether less restrictive alternatives existed.

**Type.** condition  **Support.** argued

**Holds when.**

- board action that intentionally frustrates shareholder voting
- Blasius compelling justification review

**Source quote.**

> LER deployment must be justified by evidence of severe harm to the corporation. Examples may include an activist's history of value destruction. LER should be a last-resort tool, allowing courts to scrutinize if less restrictive alternatives exist.
