# kaal:claim:7598518-022

**Claim.** A validity filter judges whether an output is correct rather than whether it is rare, so where rare content is as checkable as common content such a filter can change rare composition only through the generator's own error profile, and if collapse proceeds by under-sampling rare modes no validity filter restores them, a reputation-weighted filter included.

**Type.** mechanism  **Support.** argued

**Holds when.**

- The ceiling holds where rare content is as checkable as common content, which this design enforces by construction.
- The experiment therefore includes an oracle validity filter as a premise rather than as a result.

**Source quote.**

> A validity filter judges whether an output is correct, not whether it is rare. Where rare content is as checkable as common content, such a filter can change rare composition only through the generator's own error profile. If collapse proceeds by under-sampling rare modes, no validity filter restores them, and a reputation-weighted filter is no exception.

**From.** Wulf A. Kaal, *Can Reputation Prevent Model Collapse? A Preregistered Test of Reputation-Weighted Data Filtering* (2026)
