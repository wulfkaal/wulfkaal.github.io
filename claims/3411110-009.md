# kaal:claim:3411110-009

**Claim.** Running an alternative trading system on a blockchain cures the ATS system's traditional price discovery latency, because every trade is posted to a public ledger that everyone can access.

**Type.** mechanism  **Support.** argued

**Holds when.**

- ATS operating on a public blockchain ledger

**Source quote.**

> By creating an ATS that trades securities over blockchain, there is no latency in price discovery, which has traditionally been a criticism of the ATS system. This is because every trade is posted to a public ledger to which everyone has access.
