# kaal:claim:3396542-017

**Claim.** The value of a token is not uniform across tokens: it depends on whether the token is currently encumbered and, for encumbered tokens, the sooner the token is expected to be released from encumbrance the greater its value.

**Type.** mechanism  **Support.** argued

**Holds when.**

- steady state DAO

**Source quote.**

> In general, the sooner a token is expected to be released from encumbrance (by the policy on which it is staked terminating due to either a payout or reaching maturity), the greater its value.
