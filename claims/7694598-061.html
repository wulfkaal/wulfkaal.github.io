Claim. For the tested open-weight agents, the governability dividend demonstrated so far is observability, not a gain in task performance.

Type. empirical · Support. reported

Holds when

  • Open-weight agents of 3 to 72 billion parameters in Stage 7.

for the tested open-weight agents, permitting governed self-modification did not improve task resolution, so the dividend demonstrated so far is observability, not a gain in performance.
