# kaal:claim:3808859-009

**Claim.** Peer-to-peer architecture inverts the role of the audience: higher demand for a file produces more seeding nodes, which lowers the per-file delivery cost, whereas in client-server architecture demand consumes bandwidth proportionally.

**Type.** mechanism  **Support.** argued

**Source quote.**

> By contrast, in the peer-to-peer network, higher demand for a file triggers higher levels of seeding nodes for the high demand file. The higher seeding level for the file lowers the delivery cost for each distributed file.

**From.** Wulf A. Kaal, *Decentralization – Why We Need Technology Infrastructure Upgrades* (2021), II.6 Peer-to-Peer Networking, page 17
