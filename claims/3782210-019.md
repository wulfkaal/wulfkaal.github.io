# kaal:claim:3782210-019

**Claim.** Each new post should be able to reference older posts, so that when a new post is validated it can raise or lower the reputational value of past posts depending on how users come to perceive the precedent.

**Type.** design  **Support.** argued

**Holds when.**

- forums with permanent post histories

**Source quote.**

> If the new post is validated, their value can affect the value of past posts positively or negatively. Old posts can have their reputational value change, depending on how important users perceive the precedent for the system.
