# kaal:claim:3782210-005

**Claim.** Reputation converts a transaction from a single-stage zero-sum game into a repeated positive-sum game by holding out the promise of future business opportunities, so the value created is the improved reputation of both parties.

**Type.** mechanism  **Support.** argued

**Holds when.**
