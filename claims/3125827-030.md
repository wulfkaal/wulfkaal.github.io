# kaal:claim:3125827-030

**Claim.** A 67% active validator requirement would improve finality but is excluded from the initial SPoS implementation because, by the CAP theorem, it limits the availability of the system and arbitrarily punishes randomly selected producers when the network is partitioned.

**Type.** failure  **Support.** argued

**Holds when.**

- network partitions occur
- consensus recognizes only blocks validated by a supermajority of active validators

**Source quote.**

> More importantly, due to the CAP theorem33, it limits the availability of the system, which is why it is not included in the initial implementation.

**From.** Craig Calcaterra, Wulf A. Kaal, *Secure Proof of Stake Protocol* (2018), 5.2 Block production, page 21
