# kaal:claim:3782193-011

**Claim.** No set of written rules can be made complete: the Folk Theorems demonstrate that however rules are written, strategies exist that follow those rules yet profit the individual at the expense of the group, so a perfect secular constitution is impossible.

**Type.** failure  **Support.** argued

**Holds when.**

- any static, formally specified set of rules governing a group
