# kaal:claim:6655138-034

**Claim.** Collapsing two distinct generative components into a single loop forces aggregation of distinct quality signals into one reputation scalar, which violates the continuity condition because the aggregate function is not Lipschitz in components whose resolution outcomes have different scales.

**Type.** failure  **Support.** argued

**Holds when.**
