# kaal:claim:3782210-015

**Claim.** Reputation tokens are meaningful only if grounded in something real, so in a profit-seeking DAO all new reputation tokens must be minted in proportion to the fees the DAO earns.

**Type.** condition  **Support.** argued

**Holds when.**

- DAOs devoted to profit

**Source quote.**

> Whenever a new reputation token is minted, to be meaningful it must be grounded in something real. In any DAO devoted to profit, the foundational object is money. So all reputation tokens need to be tied to the fees the DAO earns.

**From.** Craig Calcaterra, Wulf A. Kaal, *The Importance of Reputation for the Evolution of Decentralization* (2021), Inductive argument for reputation architecture, page 6
