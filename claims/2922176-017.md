# kaal:claim:2922176-017

**Claim.** Code guidance assigning the board responsibility for long-term value creation, as in the 2016 Dutch Corporate Governance Code, is difficult to implement because neither long-term value nor the intended beneficiary of that value is defined.

**Type.** failure  **Support.** argued

**Holds when.**

- Dutch Corporate Governance Code, December 2016
