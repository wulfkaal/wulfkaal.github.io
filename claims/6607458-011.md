# kaal:claim:6607458-011

**Claim.** The computative agent is not a satisficer, because computational resources are capital rather than a fixed cognitive endowment, so added capacity scales the size and quality of the generable possibility space rather than easing a cognitive bound.

**Type.** mechanism  **Support.** argued

**Source quote.**

> The computative agent is not a satisficer. Computational resources are capital rather than a fixed cognitive endowment. An increase in computational capacity increases the size and quality of the possibility space the agent can generate
