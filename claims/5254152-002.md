# kaal:claim:5254152-002

**Claim.** Quadratic voting suppresses domination by any single participant because the cost of each additional vote rises quadratically, making concentrated control prohibitively expensive.

**Type.** mechanism  **Support.** asserted

**Holds when.**

- DAOs that implement quadratic vote pricing
