# kaal:claim:3125822-014

**Claim.** Reddit's upvote system imposes insignificant punishment for voting randomly, and this lack of cost compromises the informational value of an upvote, which is the failure mode a staked validation pool is designed to avoid.

**Type.** empirical  **Support.** evidenced

**Holds when.**

- applies to unstaked voting systems

**Source quote.**

> As a second example, Reddit's upvote system currently has insignificant punishment for voting randomly, which compromises the value of the meaning of an upvote
