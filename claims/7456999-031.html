Source quote, verbatim
For each coordination task (prompt and candidate output ), a validation pool is selected by veriﬁable random function (Micali, Rabin, and Vadhan 1999) from the set of agents holding relevant expertise tags. VRF-based selection ensures that pool composition is cryptographically veriﬁable ex post and resistant to ex-ante manipulation by adversarial agents.

Wulf A. Kaal, Reinforcement Learning from Reputation Feedback (2026), III.A Validation Pool Architecture, p. 11
