kaal:claim:3266953-029

Identity verification does not fix the sockpuppet problem, because whenever the reputation is genuinely valuable a sockpuppet operator can afford to clear whatever verification hoops are in place, including stealing biometric data, and then inflate reputation as before.

Source quote, verbatim
The problem with this is, if the reputation is genuinely valuable, a sockpuppet account can afford to go through whatever hoops you have in place to create false identities (including stealing biometric data if necessary), then increase their reputation arbitrarily, as described above.
