# kaal:claim:3782191-032

**Claim.** Concentration produces instability and dispersion produces stability: the more concentrated a structure is, the more unstable it is, because little changes can cause major structural change, while a spread out pattern remains spread out when disturbed.

**Type.** mechanism  **Support.** argued

**Holds when.**

- any structure characterized by concentration or dispersion

**Source quote.**

> The more concentrated a structure is, the more unstable it is. The more spread out a pattern is, the more stable it is
