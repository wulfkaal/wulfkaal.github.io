# kaal:claim:3995709-016

**Claim.** Without crowd controls, the reviewer's views and the author's intent are at odds and the reviewer can impose their own logic, forcing the author to rewrite functionally sound code repeatedly, which is highly time consuming and inefficient.

**Type.** failure  **Support.** argued

**Holds when.**

- legacy code review processes lacking crowd control

**Source quote.**

> Because the code reviewer may wish to impose their own logic on the code author, the code author may be required to rewrite code over and over even though the core functionality of the code is sound and dangerous issues were controlled for. This can be highly time consuming and inefficient.

**From.** Wulf A. Kaal, *How DAOs Optimize Open-Source Code Reviews and Create Open-Source Standards* (2021), Lack of Crowd Controls, page 13
