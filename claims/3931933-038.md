# kaal:claim:3931933-038

**Claim.** Governance decisions such as network upgrades follow a simple vote that mints no reputation, yet reputation in the SDAO can still be lost through a governance vote because each vote follows the DEVxDAO MVPR logic moving from loosely coupled to tightly coupled voting.

**Type.** mechanism  **Support.** asserted

**Holds when.**

- SDAO governance votes on network upgrades

**Source quote.**

> Governance decisions, such as network upgrades, among others, follow a simple vote process in which no reputation is minted. However, reputation in the SDAO can be lost as a result of a governance vote as each vote follows the DEVxDAO MVPR logic via loosely coupled to tightly coupled voting.
