# kaal:claim:3266953-027

**Claim.** Anchor tokens are highly inflationary because new ones are minted in proportion to the SEM denominated transaction fees collected in each block, so a member must keep participating simply to maintain their relative power.

**Type.** mechanism  **Support.** argued

**Holds when.**

- Anchor token holders in the block production DAO

**Source quote.**

> New Anchor tokens are created in proportion to the number of SEM denominated transaction fees collected by the system in each block. Therefore, Anchor tokens are highly inflationary. To maintain his relative power, Bob must continue to participate.
