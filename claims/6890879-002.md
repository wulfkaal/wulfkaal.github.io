# kaal:claim:6890879-002

**Claim.** Cooperation is sustained when interaction is repeated, memory of past conduct persists, and that memory has consequences; in an economy of agents those conditions must be supplied by an explicit, portable signal, and reputation is that signal.

**Type.** mechanism  **Support.** argued

**Holds when.**

- the practical reading of the Folk Theorems for software agents

**Source quote.**

> Cooperation is sustained when interaction is repeated, when memory of past conduct persists, and when that memory has consequences for future opportunity. In a human institution, those conditions are supplied informally by social memory and formally by law. In an economy of agents, they must be supplied by an explicit, portable signal. Reputation is that signal.

**From.** Wulf A. Kaal, *From Neoclassical to Computative Labor: Foundations for a Testable Theory of Reputation Governance in the Agent Economy* (2026), II. The Foundational Theorem, page 2
