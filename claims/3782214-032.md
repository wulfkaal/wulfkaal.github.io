# kaal:claim:3782214-032

**Claim.** To preserve the efficiency of a self executing code is law smart contract, the appeals process must be built into the code itself, with triggers either party can engage that freeze the encumbered assets and transfer partial powers of disbursement to a third party arbiter.

**Holds when.**
