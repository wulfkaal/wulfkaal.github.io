kaal:claim:7598518-013

Claim. The study runs fixed-size replacement, the protocol on which collapse was first shown, and includes no accumulation arm, so no result it produces bears on whether a filter adds anything once real data accumulates.

Type. condition · Support. stated

Holds when

  • Applies to the replacement regime only.
  • The distinction matters because accumulating real and synthetic data keeps error bounded in the settings studied, while replacement collapses.

This paper runs fixed-size replacement, the protocol on which collapse was first shown, and has no accumulation arm, so no result here bears on whether a filter adds anything once real data accumulates.
