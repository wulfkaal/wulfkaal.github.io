# kaal:claim:3782220-024

**Claim.** Individual autonomy and group cohesion reinforce rather than substitute for each other: the network effect is achieved only when individuals subsume their freedom to act in concert with the group, and diminishing one quality diminishes the other.

**Type.** mechanism  **Support.** argued

**Holds when.**

- network organizations

**Source quote.**

> The network effect is only achieved when individuals subsume their freedom to act in concert with the group. Again, both individual autonomy and group cohesion need to be balanced to increase both qualities. Diminishing one diminishes the other.
