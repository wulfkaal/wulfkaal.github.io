# kaal:claim:4755632-020

**Claim.** More reviewers asking clarifying questions makes code simpler and clearer, which typically increases code quality, but hierarchical review processes foreclose this mechanism and also exclude opinions from the edges of the reviewer spectrum.

**Type.** failure  **Support.** argued

**Holds when.**

- applies to hierarchical code review processes

**Source quote.**

> the more people review the code with comments that ask for clarification, the more likely it becomes that the code becomes simpler and clearer, which in turn typically increases code quality. However, that is not possible in hierarchical review processes.

**From.** Wulf A. Kaal, *AI Learning - Decentralized Governance to Optimize Human Output Datasets for AI Learning* (2024), Market for Code Reviews, page 34
