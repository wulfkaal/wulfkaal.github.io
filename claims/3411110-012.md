# kaal:claim:3411110-012

**Claim.** Transfer agents become unnecessary in blockchain based trading models because every function they perform, including maintaining the holding record, can be automated in code and is already produced by the ledger's design.

**Type.** mechanism  **Support.** argued

**Holds when.**

- fully blockchain based trading and settlement models

**Source quote.**

> In blockchain- based trading models, transfer agents will not be needed because every task they preform can be automated through coding.
