# kaal:claim:3782214-006

**Claim.** Declining to adopt explicit or formal rules is itself a governance choice, and it defaults to rule by might; since might in these systems is defined by wealth, the resulting order is oligarchy.

**Type.** failure  **Support.** argued

**Holds when.**

- platforms where power tracks token holdings or computing power

**Source quote.**

> Choosing no explicit or formal rules is still a governance choice. That choice de- faults to the prehistoric rule of might makes right. Since might is defined by wealth, they've chosen oligarchy.
