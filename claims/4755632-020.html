kaal:claim:4755632-020

More reviewers asking clarifying questions makes code simpler and clearer, which typically increases code quality, but hierarchical review processes foreclose this mechanism and also exclude opinions from the edges of the reviewer spectrum.

Source quote, verbatim
the more people review the code with comments that ask for clarification, the more likely it becomes that the code becomes simpler and clearer, which in turn typically increases code quality. However, that is not possible in hierarchical review processes.
