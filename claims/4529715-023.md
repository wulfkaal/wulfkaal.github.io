# kaal:claim:4529715-023

**Claim.** Blockchains cannot access off-chain data, and resolving this by using centralized oracles nullifies the advantages of decentralized systems while creating major security risks such as bribing and intimidation.

**Type.** failure  **Support.** argued

**Holds when.**

**Source quote.**
