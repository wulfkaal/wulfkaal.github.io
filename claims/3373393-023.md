# kaal:claim:3373393-023

**Claim.** The distributed consensus model, in which network nodes verify and validate transactions before execution, makes it extremely rare for a fraudulent transaction to be recorded in the blockchain, and it does so without compromising the privacy of the parties.

**Type.** mechanism  **Support.** argued

**Source quote.**

> Blockchains' distributed consensus model, e.g. the network "nodes" verify and validate chain transactions before transaction execution, makes it extremely rare for a fraudulent transaction to be recorded in the blockchain.

**From.** Wulf A. Kaal, *Blockchain Solutions for Agency Problems in Corporate Governance* (2019), III.1 Blockchain Guarantees, page 15
