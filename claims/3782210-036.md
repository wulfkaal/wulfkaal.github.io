# kaal:claim:3782210-036

**Claim.** A meaningful reputational system with the potential for retrospective review would let a network rely on fewer nodes, since randomly selected nodes staking their reputation can do the polling work and be reviewed and punished later, which is one reason proof of stake is more efficient than proof of work.

**Type.** design  **Support.** argued

**Holds when.**

- consensus is near unanimous nearly all the time
- Byzantine behavior is detectable on later review

**Source quote.**

> But if we had a meaningful reputa- tional system with the potential for review, we could rely on fewer nodes. This mech- anism is one reason proof of stake is more efficient than proof of work.
