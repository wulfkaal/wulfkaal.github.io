# kaal:claim:3782193-032

**Claim.** Adding reputation to the contracting game converts it from a single-stage zero-sum game into a repeated positive-sum game in which the rest of the community becomes relevant, because reputation is a future-oriented commodity that pays off with the promise of future contracts.

**Type.** mechanism  **Support.** argued

**Holds when.**

- networks where reputation is observable and policed by the community

**Source quote.**

> By adding reputation to the game, it becomes a repeated game, and the rest of the community becomes relevant. Reputation is a future-oriented commodity, which pays off profits with the promise of future contracts. Now the game is a repeated game which is positive-sum.

**From.** Craig Calcaterra, Wulf A. Kaal, *Historical Sketches of Centralization vs. Decentralization* (2021), Maghribi traders’ solution, page 26
