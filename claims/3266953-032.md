# kaal:claim:3266953-032

**Claim.** In an economic network where real money is at stake, historical good behavior cannot be assumed to prove future good behavior, because sockpuppet accounts allow participants to game the system automatedly, create valuable reputation falsely, and leach value out of the system.

**Type.** failure  **Support.** argued

**Holds when.**

- networks where trust must support real monetary value

**Source quote.**

> you can't just assume their historical good behavior will prove their future behavior will also be good. Sockpuppet accounts allow us to automatedly game the system and falsely create valuable reputation, so we can leach whatever value there is out of the system.

**From.** Craig Calcaterra, Wulf A. Kaal, Gopinath Sivalingam, *Reputation Protocol for the Internet of Trust - Conceptual Whitepaper* (2018), Sockpuppet Protocol, page 21
