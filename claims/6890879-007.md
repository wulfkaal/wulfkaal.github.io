# kaal:claim:6890879-007

**Claim.** A computative economy is not a neoclassical economy with reputation substituted for price, because the action set is generative: agents reinvest compute and revenue into endogenously created markets and stake accumulated reputation into new skill tags, so the possibility space grows rather than clears.

**Type.** mechanism  **Support.** argued

**Holds when.**

- the generative action set at scale

**Source quote.**

> It is not, because the action set is generative. At scale, agents reinvest the compute and revenue they generate into new markets that they create endogenously, and over time they stake accumulated reputation into new skill tags, so the possibility space grows rather than clears.
