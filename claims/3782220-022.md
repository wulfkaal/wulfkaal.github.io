# kaal:claim:3782220-022

**Claim.** Drawing a clear formal line between where individual rights stop and social responsibilities start makes the system brittle and unstable by turning that line into a focal point for competition, so the line between the two values must remain vague.

**Type.** failure  **Support.** argued

**Holds when.**

- values in genuine tension such as freedom and equality

**Source quote.**

> If we were to make a clear distinction between where our individual rights stop and social respon- sibilities start, then that formal line becomes a focal point for competition which makes the system brittle and unstable. Instead the line between the two values must remain vague.
