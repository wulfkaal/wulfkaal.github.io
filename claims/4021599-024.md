# kaal:claim:4021599-024

**Claim.** A utility token's value depends on its functions and therefore correlates with actual demand for the token, so a scaled up project with a high number of users usually yields increased utility token value, whereas a securities token's value correlates with the value of the issuing company.

**Type.** mechanism  **Support.** argued

**Source quote.**

> That is, a scaled-up project with a high number of users usually result in increased utility token value. By contrast, the value of securities tokens is often correlated to the value of the token issuing company.40
