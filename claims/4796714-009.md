# kaal:claim:4796714-009

**Claim.** Federated learning does not eliminate privacy risk, because although the data stays decentralized the exchange of model parameters can still expose sensitive information if those parameters are intercepted or improperly handled.

**Type.** failure  **Support.** evidenced

**Holds when.**

- applies to practical federated learning deployments
- risk arises at the parameter exchange step

**Source quote.**

> These challenges arise because, while FL keeps data decentralized, it still involves the exchange of model parameters, which could potentially expose sensitive information if intercepted or improperly handled.
