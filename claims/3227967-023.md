# kaal:claim:3227967-023

**Claim.** A decentralized autonomous organization is merely computer code with no directors, managers or employees, its governance structure built with software, code and smart contracts running on a public decentralized blockchain platform.

**Type.** definitional  **Support.** asserted

**Holds when.**

- DAOs built on public platforms, in most cases Ethereum

**Source quote.**

> DAOs are "merely" computer code. They don't have any directors, managers or employees. The governance structure is built with and on software, code and smart contracts that ran on a public decentralized blockchain platform (in most cases Ethereum).

**From.** Mark Fenwick, Wulf A. Kaal, Erik P.M. Vermeulen, *Legal Education in a Digital Age Why 'Coding for Lawyers' Matters* (2018), VII. Smart Contracts, page 25
