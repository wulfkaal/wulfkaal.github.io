A decentralized autonomous organization is merely computer code with no directors, managers or employees, its governance structure built with software, code and smart contracts running on a public decentralized blockchain platform.

Source quote, verbatim
DAOs are "merely" computer code. They don't have any directors, managers or employees. The governance structure is built with and on software, code and smart contracts that ran on a public decentralized blockchain platform (in most cases Ethereum).
