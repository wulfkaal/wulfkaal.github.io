# kaal:claim:7456999-056

**Claim.** A reward signal based only on an externally checked outcome can be style-invariant by construction, but this does not extend to a pool resolution or fitted reward model.

**Type.** condition  **Support.** argued

**Holds when.**

- an externally checked outcome that is invariant to the specified style dimension

**Source quote.**

> An externally checked outcome can be invariant to style by construction. A conﬁdently formatted incorrect answer then receives the same signal as a poorly formatted one. This claim does not extend to a pool resolution . Style can move validators, and nothing in the mechanism prevents it. It also does not extend automatically to the reward model in Part VI, which can learn style correlations absent from .
