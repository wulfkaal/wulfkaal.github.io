# kaal:claim:3949098-013

**Claim.** Exit by selling reputation tokens is more problematic for reputation than for other cryptocurrency tokens, because reputation is less fungible: a token's value is tied to the specific post in which the reputation was created and is subject to separate review.

**Type.** failure  **Support.** argued

**Holds when.**

- a member wants to exit by selling reputation tokens at fair market value

**Source quote.**

> This is more problematic for reputation than for most other cryptocurrency tokens, since reputation is less fungible because a token's value is tied to the post in which the reputation was created and subject to separate review. But in principle it could be algorithmically valued.
