# kaal:claim:3125827-025

**Claim.** In SPoS, validators download the most recently upvoted validation algorithm and faithfully running it unedited automatically produces the winning vote, so honest validators are rewarded; this holds on the assumption that users controlling 51% of sem token power act honestly.

**Type.** condition  **Support.** argued

**Holds when.**

- users holding 51% of sem token power act honestly
- honesty defined as running the forum approved algorithm unedited

**Source quote.**

> Faithfully running this algorithm on the block will automatically choose the correct vote to win the validation pool, rewarding honest validators, assuming users with 51% of sem token power act honestly. Honesty is defined as faithfully running the algorithm, unedited.
