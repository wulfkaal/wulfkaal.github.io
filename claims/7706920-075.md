# kaal:claim:7706920-075

**Claim.** If earnings pass to an operator the operator is the residual claimant and the principal remains, so the model's results fail where earnings do not belong to the agent.

**Type.** failure  **Support.** argued

**Holds when.**

- The model assumes that the agent holds the earnings from which it is garnished and that an enforcer outside the model attaches the obligation to the record.

**Source quote.**

> Earnings may not belong to the agent. The model assumes that the agent holds the earnings from which it is garnished and that an enforcer outside the model attaches the obligation to the record. If earnings pass to an operator, the operator is the residual claimant and the principal remains.
