# kaal:claim:4755632-010

**Claim.** Human shortcomings in micro task work such as limited attention span, irrationality, and inaccuracy create verification requirements, but manual verification is performed by humans subject to the same limitations, so verification does not resolve the quality problem it is meant to solve.

**Type.** failure  **Support.** argued

**Holds when.**

- applies where verification of micro task work is itself manual

**Source quote.**

> However, manual verification of micro task work is subject to the same human limitations.
