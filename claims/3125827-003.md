# kaal:claim:3125827-003

**Claim.** A secure proof of stake protocol requires an incentive structure that perpetually motivates users to do three things at once: produce valuable blocks, police blocks that violate protocol, and improve the production protocols in response to gaming. Incentivizing only block production is insufficient.

**Type.** condition  **Support.** argued

**Holds when.**

- decentralized systems without a central enforcement authority

**Source quote.**

> A secure PoS protocol requires a proper incentive structure which perpetually motivates users to produce valuable blocks, to police the production of blocks which violate protocols, and to improve block production protocols in response to gaming.
