# kaal:claim:2267560-041

**Claim.** Contracting parties need to postpone the specification of obligations only if the feedback process in the dynamic framework did not generate sufficient information; where sufficient information is available, contractual incompleteness can be lowered.

**Type.** condition  **Support.** argued

**Holds when.**

- sufficient information is generated by the feedback process
