kaal:claim:7598518-039

Claim. Because no standard deviation was known before the runs, the design fixes a masked release in which the analysis releases only each test's variance of paired differences, withholds the mean, and reports the realized power first, and if the realized conjunction power is below 0.80 the substrate is reported as underpowered with the same prominence as any label.

Type. design · Support. stated

Holds when

  • The masked release is fixed in the design rather than chosen after the outcomes existed.
  • Whether the substrate is underpowered is not known until the gate opens.

Source quote

No standard deviation was known before the runs, so the design fixes a masked release: after the gate opens, the analysis releases only each test's variance of paired differences, withholds the mean, and reports the realized power first. If the realized conjunction power is below 0. 80, the substrate is reported as underpowered, with the same prominence as any label.

From. Wulf A. Kaal, Can Reputation Prevent Model Collapse? A Preregistered Test of Reputation-Weighted Data Filtering (2026). Full text.
