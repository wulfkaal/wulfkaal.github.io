Claim. The analysis refuses to unseal unless the design hash is accepted, the tree is clean and matches its commit byte for byte, and the code differs from the audited commits only in a named allowlist.

Type. mechanism · Support. stated

Holds when

  • Describes the unseal procedure of Section VI.
  • The refusal is a property of the analysis code, which the paper states was audited before any outcome was read.

Source quote

The analysis checks each manifest's provenance, checks every sealed file against its digest before reading it, and records a digest of every file the variance release reads, refusing at unseal if any changed. It refuses unless the design hash is accepted, the tree is clean and matches its commit byte for byte, and the code differs from the audited commits only in a named allowlist.

From. Wulf A. Kaal, Can Reputation Prevent Model Collapse? A Preregistered Test of Reputation-Weighted Data Filtering (2026). Full text.
