# kaal:claim:6192998-027

**Claim.** Constraining the citation weight parameter below one and enforcing row stochasticity through normalization guarantees that the citation weighted value vector exists, is unique, and converges, which resolves the instability of the original recursive valuation formula.

**Type.** condition  **Support.** evidenced

**Holds when.**

- citation weight parameter strictly less than one
- contribution matrix normalized to be row stochastic
