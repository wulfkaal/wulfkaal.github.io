# kaal:claim:3249860-036

**Claim.** App-specific tokens exert less influence over value from other projects and typically fail to support a broader user market, because their limited use curtails user access.

**Type.** failure  **Support.** argued

**Holds when.**

- tokens fundamentally restricted for use in a given ecosystem

**Source quote.**

> App-specific tokens generally can exert less influence over the value from other projects. App-specific tokens also typically do not allow for a broader user market as the limited use of the token curtails user access.
