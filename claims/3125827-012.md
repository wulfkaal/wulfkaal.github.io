# kaal:claim:3125827-012

**Claim.** No consensus protocol can guard against Byzantine faults when a single transaction is worth more than the promise of all future fees for the entire platform, because in that case a party can profitably bribe the whole node set to destroy the chain's own integrity.

**Type.** failure  **Support.** argued

**Holds when.**

- a single transaction whose value exceeds the present value of all future platform fees

**Source quote.**

> No protocol can guard against Byzantine faults if a transaction is more valuable than the promise of all future fees for the entire platform; in this case a party could bribe the entire set of nodes (or 51%)

**From.** Craig Calcaterra, Wulf A. Kaal, *Secure Proof of Stake Protocol* (2018), 2.2 Soft attacks, page 8
