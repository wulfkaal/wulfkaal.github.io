# kaal:claim:3782203-035

**Claim.** A DAO permitting anonymous membership is exposed to a sockpuppet attack in which one account behaves honestly while another cheats, and if the cheating account can funnel its gains to the honest account without detection or punishment the system is set up for failure.

**Type.** failure  **Support.** argued

**Holds when.**

- anonymous DAOs allowing multiple accounts per person

**Source quote.**

> One strategy is to have one account which acts honestly and one which cheats. If the cheating account can funnel the gains to the honest account, without detection or punishment, this sets the system up for failure.

**From.** Craig Calcaterra, Wulf A. Kaal, *A Technical Perspective on Decentralization* (2021), Application to reputation tokens, page 21
