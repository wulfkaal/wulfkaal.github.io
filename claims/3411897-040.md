# kaal:claim:3411897-040

**Claim.** For any static set of rules in an infinitely repeated game using reputation stakes, there is a way to subvert the rules for an individual's profit at the expense of the group, which is why static decentralized governance rules can always be gamed and only dynamic, changing rules can address the problem.

**Type.** failure  **Support.** argued

**Holds when.**

- infinitely repeated games with reputation or stake based rules
- static rule sets

**Source quote.**

> For any static set of rules in an infinitely repeated game using reputation (stakes), there is a way to subvert the rules for an individual's profit at the expense of the group.
