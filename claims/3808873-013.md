# kaal:claim:3808873-013

**Claim.** Applying decentralized technology to optimize a legacy system, for example using blockchain to improve the malfunctioning shareholder proxy voting process, perpetuates the outdated and malfunctioning centralized system rather than replacing it with a better performing decentralized one.

**Type.** failure  **Support.** argued

**Holds when.**

- decentralized technology deployed as an optimization layer on centralized legacy processes

**Source quote.**

> In the process, the outdated and malfunctioning centralized legacy systems are being perpetuated rather than being replaced with better performing decentralized systems.
