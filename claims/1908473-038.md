# kaal:claim:1908473-038

**Claim.** Because the Bankruptcy Code does not define adequate information, prepackaged plans risk inadequate disclosure, creditor challenge, and unusable prepetition votes that force the case into the longer ordinary Chapter 11 confirmation procedure.

**Type.** failure  **Support.** argued

**Source quote.**
