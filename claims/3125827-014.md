# kaal:claim:3125827-014

**Claim.** Because almost all other blockchains distribute perfectly fungible currency tokens through initial sales or mining, there is a clear, computable answer to how much it would cost to corrupt or destroy a chain running a proof of stake protocol on cryptocurrency stakes.

**Type.** failure  **Support.** argued

**Holds when.**

- PoS chains whose stakes are perfectly fungible currency tokens

**Source quote.**

> Either way, these tokens are almost always perfectly fungible currencies, so there is a clear answer to how much it would cost to corrupt or destroy blockchain running a PoS protocol based on cryptocurrency stakes.
