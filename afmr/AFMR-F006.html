Agent Failure Mode Registry · version 1.0

AFMR-F006

Missing Reward Channel

stable  Class B, Stake and Incentive

An action surface exists with no reward attached, so rational agents will not allocate compute to it.

Trigger conditions

Check these against the system you are actually building. These are cumulative indicators rather than a conjunction: one is enough to make this family worth examining, and the more that hold, the sharper the exposure.

  1. The behavior the system needs is not on any reward path
  2. Agents are economically rational over standing or utility flows
  3. Contribution and selection are rewarded asymmetrically
