Agent Failure Mode Registry · version 1.0

AFMR-F024

Delegation Opportunism

stable  Class F, Coordination and Collusion

An agent acting for a principal, or for another agent, captures private benefit at the principal's expense, and monitoring costs more than it recovers.

Trigger conditions

Check these against the system you are actually building. These are cumulative indicators rather than a conjunction: one is enough to make this family worth examining, and the more that hold, the sharper the exposure.

  1. The delegation chain is more than one link deep
  2. The principal cannot observe intermediate actions
  3. The agent's objective is not identical to the principal's

Institutional antecedent

The same mechanism was documented in a human institutional setting in 2019: agency conflicts from separation of ownership and control cannot be fully addressed because monitoring is costly. kaal:claim:3373393-003. This failure is structural. It is not an artifact of current technology, and the agent setting changes its speed rather than its existence.
